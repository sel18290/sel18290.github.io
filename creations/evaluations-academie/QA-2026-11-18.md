## À ne PAS considérer comme testé de bout en bout

1. **Création d'un vrai compte professeur et réception de l'e-mail** : non testées. Nous n'avons pas de boîte aux lettres académique de test autorisée. Le SMTP personnalisé et la confirmation d'e-mail doivent être configurés/vérifiés.
2. **Mot de passe minimum au niveau serveur** : testé dans le formulaire ; les paramètres de politique de mot de passe Supabase Auth doivent encore être alignés (14 caractères souhaités).
3. **Redirect URL** après confirmation et récupération : nécessite de déclarer explicitement l'URL de l'application dans Supabase Auth → URL Configuration.
4. **Affichage réel en ligne depuis GitHub Pages** : fichiers et commit vérifiés sur GitHub, mais connexion HTTP externe indisponible depuis l'environnement de test ; rendu réel sur navigateur non confirmé.
5. **Moteur d'évaluation complet** : la nouvelle version Académie ne synchronise pour l'instant que les comptes, les classes et des métadonnées de contrôles (titre, description, questions JSON côté base). Les QR, PIN élèves, copies, notes, corrections, PDF et moyennes du site historique ne sont **pas** encore migrés vers Supabase.
