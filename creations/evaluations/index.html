Architecture du projet

Le site GitHub Pages présente le portail. Les contrôles, sessions, réponses, notes et événements de visibilité sont enregistrés sur un serveur Python/SQLite sécurisé ; la correction IA optionnelle s'effectue avec Ollama et Qwen sur une machine privée. Les notes officielles sont validées par le professeur.

Aucune donnée d'élève ne doit être déposée dans ce dépôt GitHub public. Le système de correction et les copies ne sont pas encore disponibles sur cette page tant que le serveur n'est pas connecté et autorisé par l'établissement.
