Note les FPS, les pixels, le temps CPU et, s’il est disponible, le temps GPU. Pour tenir 60 FPS, chaque image doit être prête en environ 16,7 ms. Les temps CPU et GPU peuvent se recouvrir : ils ne s’additionnent pas.

Le temps CPU mesure la préparation et la soumission du rendu. L’absence de temps GPU signifie que le navigateur ne fournit pas cette mesure. Ce comparatif conserve les objectifs enregistrés.
